# mania-id

> **⚠️ This project is no longer maintained.**
> [quorid](https://github.com/juanmaneo/quorid) is the direct evolution of mania-id.
> Nothing more will be done on mania-id: it served its purpose.
> Please head over to [quorid](https://github.com/juanmaneo/quorid) for all future development.

This is just a unique id generator made for fun and testing DB implementations
It's using on purpose a UTF-8 emoji alphabet.
There are 2 variants a short one using only fruits and a more crazy one.
